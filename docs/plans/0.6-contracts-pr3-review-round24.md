### F1 [LOW] The legal-recursion control never follows the recursive reference

`test_a_self_referencing_inline_operation_schema_earns_a_named_drift_not_a_crash`
(`tools/contracts/tests/test_contract_documents.py`, the third control) puts
the self-pointer under `properties.child` — but the committed
`backend/valid/derivative-response-200` body has no `child` member, so jsonschema
never evaluates the recursive `$ref` at all and the assertion
`{API_SCHEMA_MISSING_FIELD}` only ever sees the root-level `required`. The
control therefore does not prove what it says: that instance-consuming
recursion still *evaluates*.

**Fix (implement as specified).** Drive the control through the fixture's
existing `crop` object (`crop: {x, y, width, height}` — present in the
committed body) and assert a finding at the nested location:

- The inline node becomes
  `{"type": "object", "properties": {"crop": {"$ref": <self pointer>}},
  "required": ["reviewed_round24_field"]}`.
- Evaluation must now descend: the root charges the missing required member
  at the vector itself, and the `crop` member — evaluated against the very
  same node through the self-pointer — charges it again with `crop` as the
  error path. The recursion terminates on its own because `crop` has no
  nested `crop` (instance consumption).
- Assert exactly two `API_SCHEMA_MISSING_FIELD` violations: one at
  `{id}` and one at `{id} at crop`, both naming `reviewed_round24_field`,
  and no `SPEC_COMPONENT_DRIFT` — a nested-location finding is only
  producible if the recursive reference was actually followed.

### F2 [LOW] `RecursionError` is not always a cycle

`_rooted_schema_errors` (api_validate.py ~L740) reports every
`RecursionError` as "revisits an in-flight schema ... (reference cycle)". A
sufficiently deep *acyclic* schema reaches the same exception, so the
finding currently asserts a diagnosis it cannot make.

**Fix.** Report the observable fact and demote the cycle to a possible
cause: the reason text becomes

> `$ref evaluation exceeded Python's recursion limit; a reference cycle
> revisiting an in-flight schema without consuming the instance is a likely
> cause`

The docstring follows ("names no pointer, and a cycle is a likely cause, not
a proven one"). `SPEC_COMPONENT_DRIFT` and the fallback structure are
unchanged. The cycle control in the unit now pins both substrings
`"recursion limit"` and `"reference cycle"` — the former is the red
discriminator for this round (the round-23 wording ends in "maximum
recursion depth reached" and contains neither "recursion limit" in that
form).
