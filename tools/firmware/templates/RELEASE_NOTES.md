# vdog firmware — release notes

This prototype prebuilt bundle flashes the vdog 0.2.0-proto bootstrap firmware
onto a Seeed Studio XIAO ESP32S3 Sense.

## Status (must remain visible in every prototype release)

- `release_channel: prototype`
- `hardware_verified: false` — no physical-device verification evidence yet.
- `recording_available: false` — the bootstrap does not record.
- `device_ota_available: false` — no device-side OTA.

See `INSTALL.md` for the package layout and `manifest.json` for exact
identity (build ID, source SHA, images, offsets, hashes).
