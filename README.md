# Agent-ready repository template

A framework-neutral starting point for projects developed with OpenCode agents.

This repository currently contains the template configuration and documentation.
Application source, dependencies, tests, and CI have not been added yet.

Define the project's purpose, users, technical stack, commands, and constraints in
[`.agent/PROJECT.md`](.agent/PROJECT.md). Add project requirements and architecture
under `docs/` as the application develops.

Agent setup and contribution workflow are documented in [`AGENTS.md`](AGENTS.md).
